# GitHub Discussions

Community help lives in **Q&A** (Help & FAQ). **Announcements** is for maintainer updates only (GitHub locks new threads there for non-maintainers).

Welcome thread: [Welcome to UltimateDonutSMP-V2 Discussions!](https://github.com/BeestoXd/UltimateDonutSMP-V2/discussions/171)

## Maintainer: category layout

Configure under **Settings → Discussions → Categories**:

| Category | Format | Purpose |
| --- | --- | --- |
| Announcements | Announcement | Releases and official news (maintainers create threads) |
| Q&A | Question & Answer | Setup help and FAQ-style questions from the community |

Remove **General**, **Ideas**, **Polls**, and **Show and tell**, or change each to **Announcement** so only maintainers can open new threads. Rename **Q&A** to **Help & FAQ** if you want that label in the picker.

Repository templates: `.github/DISCUSSION_TEMPLATE/q-a.yml` and `announcements.yml`. Wrong-category community posts are moved to Q&A by `.github/workflows/discussion-help-only.yml`.
